## Recommended reading path

If you are upgrading:

1. Read the latest release notes.
2. Read [../UPGRADE.md](../UPGRADE.md).
3. Verify the artifact with [../ARTIFACTS.md](../ARTIFACTS.md) guidance.
4. Run `linux-maint verify-install` and `linux-maint status` after the upgrade.
