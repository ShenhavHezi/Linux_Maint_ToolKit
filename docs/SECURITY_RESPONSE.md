# Security Response

We take security reports seriously and aim to respond quickly and responsibly.

## How to report

Please open a security advisory or send a private report describing:
- The issue and impact
- Steps to reproduce
- Suggested fix (if known)

If you cannot use GitHub Security Advisories, email the maintainer listed in `SECURITY.md`.

## What to expect

- Initial acknowledgment within 3 business days
- Status updates during investigation
- Coordinated disclosure once a fix is available

## Scope

This policy applies to:
- The `linux-maint` CLI and wrapper
- Monitor scripts under `monitors/`
- Tools under `tools/`

Out of scope:
- Third‑party package vulnerabilities
- Issues requiring elevated access that is already controlled by the operator
